# Orbit MCP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline.

**Goal:** Expose local Orbit queries to desktop clients through SSH MCP.
**Architecture:** One Python module owns config, a bounded subprocess runner,
and four MCP handlers. The official SDK implements the protocol.
**Tech Stack:** Python >=3.11, mcp 2.3.x, pytest, OpenSSH, Orbit CLI.
**Spec:** ../specs/2026-10-30-orbit-mcp-design.md

## Global Constraints

- No GitLab implementation code; no credentials or personal configuration in Git.
- Only explicitly configured Git roots; local file context, literal search.
- No shell interpolation or HTTP listener. Output limit and subprocess deadline.

## Review Focus

- Unknown repos, traversal, external symlinks, and remote-looking targets fail.
- Search text resembling options or GitLab qualifiers remains literal.
- Timeouts, cancellation, and excessive output release the process and its children.
- CLI errors reach clients as tool errors; no matches are an empty successful search.
- Actual SDK stdio handshake and actual Orbit queries work through SSH.
